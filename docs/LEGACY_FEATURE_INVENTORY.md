## Local integration decision

Reuse the existing frozen integrated projection and deterministic presentation
helpers through an explicit development-only, loopback connection. Keep the
public v0.1 validator unchanged and disabled local-demo mode in production.
No iframe replaces the new MatDREAMS pages. No private data, evidence text,
provenance, PDFs, or generated research artifacts are copied into this repository.

Fresh probes executed only read operations: source inspection, raw graph SHA,
and a Node invocation of the existing pure selectors against the actual client.
They establish selector behavior and counts, not successful browser interaction.
Integrated browser verification belongs to the implementation phases.
